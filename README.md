# hymn

Personal portfolio site built with Astro.

## Stack

- Astro 5
- React 18
- Tailwind CSS 3

## Run it

```bash
npm install
npm run dev
```

```bash
npm run build   # production build into dist/
npm run preview # preview the build
```
